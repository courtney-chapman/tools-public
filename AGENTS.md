# Repository Instructions

For commits in this public repository, use its configured Git author and
committer identity, including the configured GitHub noreply email. Never replace
that identity with a guessed account name, email address, or numeric user ID.
Add a `Co-authored-by` trailer only for a real co-author identified by the owner
with the email to use; never add one for the commit's author.

Before opening or merging a pull request, check each commit's author,
committer, and full message. Inspect the proposed squash message for unwanted
co-author credit. Stop before publication if attribution is wrong or uncertain.
After merging, verify the published commit's author, committer, and message on
GitHub. A GitHub-created squash commit may list GitHub as its committer; check
that against the merge method, and still check the author and full message for
false attribution.
