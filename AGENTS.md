Agent instructions

Commits use this repository's configured author identity and GitHub noreply email. Add a Co-authored-by trailer only for a real co-author the owner names. Before publishing, confirm each commit's author, committer and full message, including squash merges.

## Browser-app publication gate

Before requesting owner approval or publishing a browser app or catalog change,
identify the approved source and final file for each image and verify their
hashes. Do not replace a named supplied image with generated art without owner
direction. Show the final catalog card beside peer cards at desktop and phone
widths. Compare any screen depicted in its graphic with the current app; if it
is stale, stop for updated art or an explicit owner disposition.

List the exact label and target URL of every card action. Verify the actions
match the established card pattern and the requested download format, then run
the relevant catalog and repository checks. Include the visual and link evidence
with the exact candidate presented for approval. File-loading and link-existence
checks alone do not satisfy this gate.
