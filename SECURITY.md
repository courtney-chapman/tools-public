# Security Policy

## Supported source

Only the current `main` branch is maintained. Release ZIPs are snapshots; include
the release tag if a report concerns a downloaded or installed copy.

## Reporting a vulnerability

Use GitHub's private vulnerability-reporting channel for this repository. Do not
open a public issue containing credentials, private data, exploit details, or
sensitive procurement information.

Include the affected plugin, relevant file or version, observed behavior, and a
minimal disclosure-safe reproduction. Do not attach real case files, source
selection information, controlled data, credentials, or personal information.
