# Regulatory reference notes

Verified 2026-11-26 against authoritative public sources. Recheck before a public release or when the FAR/CPARS guidance changes.

| Source | Supported use | Limit |
| --- | --- | --- |
| [FAR 42.1502(a)](https://www.acquisition.gov/far/42.1502) | At least annual and completion past-performance evaluations, where applicable. | Other paragraphs govern contract/order applicability and exceptions. This tool requires user confirmation. |
| [FAR 42.1503(b), (d), (f)](https://www.acquisition.gov/far/42.1503) | Standard factors and five ratings; up to 14 calendar days following CPARS notification for initial contractor comments; Government updates for later comments. | The official CPARS notification and displayed deadline control the working record. The tool permits corrections and does not assign ratings. |
| [CPARS Guidance, §§4.8–4.9](https://www.cpars.gov/cparsweb/assets/documents/CPARS-Guidance.pdf) | Guidance states the entire evaluation process shall be completed within 120 days after the end of the evaluation performance period. | This is CPARS guidance, separately labeled from FAR. Confirm current agency-specific requirements or deviations; document overrides. |
| [CPARS User Manual](https://www.cpars.gov/cparsweb/assets/documents/CPARS_User_Manual.pdf) | Describes the system due date as period end plus 120 days. | Supplementary system instruction; not a separate FAR requirement. |

The performance period end date and Government completion date are distinct. The 30-day expected availability date in the app is an internal planning assumption, not a Government requirement. The 14-day comment suggestion is based on actual notification, never the performance period. Short, modified, final, and order-level schedules require user review.
