Procurement File Readiness Checklist

Internal documentation review for Government prime contractor purchasing

1 Details2 Controls3 Checklist4 Report

1. Procurement details

Record the purchasing facts you know.

New here? How this works
  1. Enter the purchasing facts; leave uncertain answers as Unknown.
  2. Review each record and select a finding. File names or IDs are optional; the app does not open files.
  3. Use Report to record an optional second review and save the full session as JSON.

2. Applicable controls

Use the prime contract and incorporated clauses. Leave uncertain answers as Unknown.

3. Checklist

Review the actual record and record your finding. Built-in rows do not cover every contract clause; add others in Parts 2 and 3.

Add or load company requirements

Company items are user-entered policy controls, separate from contract and regulatory items.

Load up to 100 rows from the CSV template. Existing JSON lists also work. Repeated records are rejected without changing the list.

Add or load agency-specific requirements

Record the governing agency provision or contract reference. These user-entered items stay separate from the built-in checklist.

Load up to 100 rows from the CSV template. Existing JSON lists also work. Confirm each cited provision and its applicability.

4. Report

Review the summary before copying, printing, or sharing.

Optional second passInternal reviewer

The buyer prepares the file. A separate reviewer can record a documentation check here; this is not an approval or CPSR determination.

Only selected JSON is read locally; nothing saves automatically. In print settings, turn off Headers and footers to omit the local file path. Confirm authorization before sharing data with an external AI service.
