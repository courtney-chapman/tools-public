# Limits of this preparation tool

- The tool organizes user-entered information. It does not verify ownership, Government title, accountable contract, quantities, condition, identities, source documents, or applicable clauses.
- A preparation exception is a missing or invalid working value, not a regulatory violation. A checklist status is a user-marked work state, not a compliance result.
- The property listing CSV is a working document. It is not SF 1428, an electronic inventory disposal schedule, a PIEE GFP Module record, or a Government submission.
- The tool does not choose a disposition path, issue Government instructions, grant approval, authorize movement or disposal, calculate deadlines, or relieve stewardship.
- Special property, hazardous or classified material, aircraft, scrap, termination inventory, subcontractor property, and other conditional cases require separate contract and official review. The tool gives no handling or disposal instructions.
- Imported rows with structural errors or missing core values are shown as skipped. Valid imported data is added only after confirmation. Editing or downloading a working list does not change the source CSV or an authoritative property record.
- Entered data is held only in browser memory and lost on reload or close. CSV and PDF files created by the user are outside the app. The app has no network or persistent storage.
- Public sources and form wording are fixed at Revision 1 and do not update automatically. No ongoing support or regulatory currency is promised.
