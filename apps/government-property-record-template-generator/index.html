These CSVs are not a transaction system and do not replace source documents, procedures, or complete contract-specific records.

Which property identifier is which?

Quick reference only. The contract and applicable clauses determine which identifiers are needed. This does not add columns or determine IUID requirements.

  • Internal asset identifier

    An organization-assigned tracking reference, distinct from a manufacturer's serial number or a DoD UII. There is no separate Asset Identifier column here. The optional Record ID links this tool's two example files; it does not establish that a local ID satisfies an individual-item tracking requirement. FAR 52.245-1(f)(1)(iii)(A)(4).

  • Manufacturer serial number

    Distinguishes a unit within the manufacturer's numbering, but is not automatically a UII. Use the snapshot's Serial Number column when the DFARS source set is selected and a serially managed item has no UII; check the contract for other identification needs. DFARS 252.245-7005(c)(5).

  • Manufacturer part number

    Identifies an item design or type; multiple units can share one part number. The snapshot has a FAR Part Number column and, in the DFARS source set, a Manufacturer Part Number column. When the applicable DFARS clause allows it because no NSN is available, pair the manufacturer's part number with its CAGE code. FAR 52.245-1(f)(1)(iii)(A)(1); DFARS 252.245-7005(c)(1).

  • National Stock Number (NSN)

    Identifies an item of supply in the Federal catalog, not an individual physical unit. The snapshot's National Stock Number column is conditional: FAR calls for it when needed for identification or disposition; the applicable DFARS clause specifies it or an allowed alternative. FAR 52.245-1(f)(1)(iii)(A)(1); DFARS 252.245-7005(a), (c)(1).

  • Unique Item Identifier (UII)

    Distinguishes an individual item globally; a serial number or local asset ID is not automatically its UII. The snapshot's Unique Item Identifier or Equivalent column applies when available and necessary for individual-item tracking. Separate DoD marking or registration duties depend on the applicable contract. FAR 52.245-1(f)(1)(iii)(A)(4); DFARS 252.245-7005(a), (d).

  • Manufacturer CAGE code

    Identifies the manufacturer entity, not the item. The snapshot's Manufacturer CAGE Code appears in the DFARS source set as part of the conditional manufacturer CAGE plus part-number alternative to an NSN. It is distinct from the Accountable Contract CAGE Code. DFARS 252.245-7005(a), (c)(1)–(2).

Entry guidance
  • Dates: Use one consistent format; the examples use YYYY-MM-DD. Keep transaction date separate from an optional posting entry date.
  • Quantities: Use numbers in the stated unit of measure. Explain adjustments in your supporting records; the downloaded files do not calculate balances.
  • Monetary values: Enter unit acquisition cost as a number without a currency symbol. Apply the clause definition and contract terms when determining the amount.
  • Identifiers: Preserve leading zeros and exact punctuation in contract, NSN, CAGE, serial, and UII values. Format spreadsheet columns as text when importing.
  • Units of measure: Use a consistent code or term such as EA or FT, and define it in your own procedures.
