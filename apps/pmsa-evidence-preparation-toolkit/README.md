# Guided PMSA Evidence Preparation Toolkit

A standalone, offline browser demonstration for organizing document references before a Government Property Management System Analysis (PMSA). It guides users through 22 published DCMA property-management elements and produces an evidence index, an outstanding-evidence list, and a printable preparation summary. It does not assess a property management system or determine compliance.

## Use

Extract the ZIP and open `index.html` in a current browser. No installation, server, account, internet connection, or document upload is needed. The five bookmarks across the top show one step at a time:

1. **Set Up:** Enter a preparation reference and list the CAGE codes and contract numbers under review, one per line. All 22 elements start selected. Open one of six navigation groups to narrow the scope; an element can be marked outside the preparation scope with an optional explanation.
2. **Gather:** Open a group and an element to review its public-source prompts. Set statuses and notes. Each element also has an optional population and sampling popup. Gather CSV options are collapsed near the top; the download has 22 element rows and 44 prompt rows, and importing edited rows does not change scope or documents.
3. **Documents:** Add or edit a reference in a popup for a document, record-set ZIP, or backup. Link it to one or more elements, record who provided it, version status, and optional request/received dates. Switch among views by document, element, or provider; a reference linked to several elements appears under each relevant element. Search, sort by document title or request/received date, and spot references requested but not received. Edit and remove actions use labeled icons. Desktop shows a table and narrow screens show reference cards. The reference-list CSV can be edited and imported to replace the list after confirmation. No files are uploaded or inspected.
4. **Review:** See the entered CAGE codes and contract numbers, four primary counts, and six status bars showing prompt statuses by element group. Print a compact dashboard with a labeled indicator for all 22 individual elements. Green means all applicable prompts are marked Available; red means at least one is marked Not Available; yellow means requested, pending, or mixed entries. Gray and slate labels distinguish not-reviewed, not-applicable, outside-scope, and unselected elements. These colors summarize entries, not compliance. Follow-up items use the same group headings; unreviewed prompts and not-applicable explanations are in collapsed sections.
5. **Export:** Download reports from one area, or save/resume a working-session JSON from another. Print or Save as PDF either the compact dashboard or the detailed preparation summary using the browser's print dialog.

Use **Load fictional example** in Set Up to explore synthetic entries. The tool asks before replacing entered work. A **Save session JSON** control is available above every bookmark; the tool does not save automatically. A downloaded session may contain sensitive document references; handle it in an authorized environment.

For CSV imports, start with the matching download in Gather or Documents and keep its column headings. Gather imports update only the element and prompt rows present in the CSV; empty cells in those rows clear the corresponding notes. Documents imports replace the entire reference list, including when the file contains only the header. Both imports validate the whole file before asking for confirmation. CSVs are read locally and limited to 12 MB. Save a session JSON before a large import if you want a rollback copy. The session JSON preserves scope, all references, and earlier imported legacy notes; the two CSV formats are for editing their respective sections.

## Scope and limits

Revision 1. The applicable contract, incorporated clauses, deviations, and Government direction control actual obligations. The app makes no network requests.

The app stores working entries in memory for the open browser page. It does not analyze documents or ZIP contents, select samples, verify a population or sampling method, decide evidence sufficiency, issue findings, calculate compliance scores, submit reports, or authorize property actions. Provenance, version, and element-level sampling fields are user-entered descriptions only. References link to elements, not individual prompts; a link does not mean every prompt in that element is supported. The reference-list CSV preserves one row per entry, including unassigned references and request/received dates. The evidence-index CSV repeats element-level references alongside prompt statuses, element-level sampling notes, and labels their scope. The outstanding CSV includes not-reviewed prompts even though the Review page keeps them collapsed. The printable summary counts those prompts and lists follow-up items separately. It uses browser-native printing and Save as PDF on US Letter and includes sampling notes by element.

## Technical and privacy notes

Source files are plain HTML, CSS, and JavaScript with no third-party runtime dependency or build step. Session JSON contains entered preparation data, CAGE codes, contract numbers, scope choices, statuses, notes, element-level sampling information, and evidence references. Session format 4 moves sampling information to elements and adds request/received dates to references. Earlier session files with no CAGE or contract fields still import with those fields blank. Formats 1–3 still import; format 1 prompt links are converted to element links, while format 3 document-level sampling notes are preserved under linked elements. Notes from unassigned format 3 references are shown in Review and the printable summary. Import validates the structure, limits size, and rejects unknown relationships. CSV cells that could be interpreted as spreadsheet formulas are prefixed with an apostrophe on export and restored on import. No browser persistent storage is used.
