# Regulatory basis — Revision 1

**Status:** Revision 1 public-source basis for the offline application.
**Sources checked:** 2026-11-15. The app does not perform live source checks.

| [DCMA Job Aid for Government Contract Property Administration](https://www.dcma.mil/Portals/31/Documents/HQ/Contract%20Property%20Job%20Aid%20Rev4%20March%2028%202025.pdf?ver=MBOAef5kaoBwrQFEYeKx3g%3D%3D) | Rev. 4, 2025-03-28 | Principal source for the 22 element names and the broad evidence categories in each element's Source Documents and Support Documents sections, pp. 54–133. |

The DCMA Job Aid is guidance to DCMA property administrators. Its element structure and example evidence are useful for organizing preparation, but they do not themselves impose 22 separate contractor obligations. The Job Aid says contractors may address the applicable processes through the 10 FAR outcomes or another structure (Element 2, p. 60). The applicable contract, incorporated clause version, deviations, and Government direction control actual obligations.

FAR 52.245-1 describes property-management outcomes. The DCMA Job Aid uses 22 element headings to organize administrator review. The toolkit uses the published element names for navigation without treating each heading as a separate contractor obligation.

## Authority classes for evidence prompts

| Class | Meaning in the evidence catalog |
| --- | --- |
| Regulatory requirement | The cited applicable FAR clause expressly calls for the process or record described. The prompt still does not decide whether that clause is in a user's contract. |
| Conditional requirement | The cited clause requires the action only when the specified item, event, approval, or incorporated clause condition exists. |
| DCMA assessment guidance | The Job Aid identifies an example source or support document that a property administrator may review. Its presence in the guide does not make the document universally mandatory. |
| Optional preparation practice | A convenient reference or organizing note suggested by this toolkit, not a contractual requirement. |

An **evidence category** is a short label for a kind of document or reference, such as a receiving record, property record, approval, or report. It is not a prescribed document title, required file format, test step, or sufficiency criterion. The catalog is limited to two broad categories per element. Users record availability and references; the app does not inspect document contents.

## Applicability and preparation limits

- Selection of an element or a **Not Applicable** status is the user's scope note, not a legal conclusion. The app preserves an optional explanation and displays a contract-applicability notice.
- Contract-specific DFARS reporting and data requirements must be checked against the actual clause version. Do not infer them from the Job Aid or automatically apply them to non-DoD work.
- Element 8's Receipt and Issue System depends on use and Property Administrator approval under FAR 52.245-1(f)(1)(iii)(B). An absent system is not, by itself, a deficiency finding by this app.
- Elements 18 and 19 involve physical storage conditions; the Job Aid says these elements have no source documents. The catalog offers an optional location reference and conditional approvals without implying documents alone prove storage adequacy.
- Element 21 disposal and element 22 closeout may involve Plant Clearance Officer instructions and other Government direction. The toolkit organizes references without authorizing disposition or closing a contract.
- FAR 52.245-1(g) permits authorized Government review of relevant plans, systems, procedures, records, and supporting documentation; it does not prescribe this toolkit's index or preparation summary.

## How the toolkit uses these sources

The [evidence catalog](evidence-catalog.md) provides two broad, non-scoring preparation prompts per element. Conditional DFARS examples appear in applicability notes; the app does not infer reporting obligations. An optional storage-area reference is an organizing note and does not prove physical conditions.

## Contract-specific applicability

The toolkit cannot know which clause versions, deviations, approvals, reporting directions, or contract-specific property terms apply to a user's work. The user must resolve those questions from the actual contract and appropriate Government direction before treating any prompt as applicable.
