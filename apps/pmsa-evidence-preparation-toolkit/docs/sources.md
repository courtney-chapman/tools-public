# Public source register — Revision 1

Checked 2026-11-15. These links document the published text used for the tool's broad prompts. They are optional references; opening the application does not use the network. Always check the actual contract, incorporated clause versions, deviations, and direction.

**How to read this:** FAR 52.245-1 describes 10 property-management outcomes. The DCMA Job Aid breaks its review into 22 topics. This tool uses those topics to organize evidence references. The Job Aid's example documents are useful ideas, but they are not automatically required by every contract. Check your actual contract for what applies. Detailed review files, `regulatory-basis.md` and `evidence-catalog.md`, are in this same `docs` folder.
