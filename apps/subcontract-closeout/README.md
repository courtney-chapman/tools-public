# Subcontract Closeout Checklist

Document subcontract closeout work in a standalone offline browser app. Record identifying information, answer contract-specific questions, update checklist items and references, and prepare a working summary memorandum or final checklist for review. The app organizes a draft; it does not approve closeout, authorize payment or property disposition, waive a claim, or end a continuing obligation.

## Use

Open `index.html` in a current browser. The app needs no account, installation, server, or network connection.

1. **Information:** Identify the supplier and subcontract. Add deliverables and acceptance references when useful.
2. **Applicability:** Answer each question from the subcontract and available records. Leave uncertain answers as Unknown. Contract terms and an optional financial snapshot have separate collapsible sections.
3. **Checklist:** Review the conditional groups. Update each item’s status, document reference, and notes. Add contract-specific items, issues, or continuing obligations as needed. A Yes answer does not complete an item.
4. **Final documents:** Review the summary memorandum and final checklist. Both show missing information, open actions, and review questions. Copy or print either document, including an incomplete draft for preliminary review.

Entries stay in the current browser tab’s memory. **Export JSON** on Final documents saves the draft; **Import draft JSON** restores a saved draft after confirmation. **Import related JSON** recognizes selected identifiers, amounts, and references from compatible tools without adopting their conclusions. Imports read only the local JSON file you select (maximum 2 MB). Save before refreshing or closing the tab. The app does not upload or inspect supporting documents.

**Copy AI prompt** copies draft data to your clipboard; it does not send data to a service. Share subcontract information externally only when authorized. Turn off browser **Headers and footers** when printing to PDF so a local file path is not printed. Protect exported JSON and PDFs according to your organization’s requirements.

## Use limits and public references

Confirm the actual subcontract, incorporated clauses, prime-contract terms, applicable deviations, property direction, and record-retention rules. These public provisions provide context where applicable; they do not impose every Government-facing duty on each subcontract:

- [FAR 52.245-1, Government Property](https://www.acquisition.gov/far/52.245-1)
- [FAR 52.216-7, Allowable Cost and Payment](https://www.acquisition.gov/far/52.216-7)
- [FAR 52.232-7, Payments under Time-and-Materials and Labor-Hour Contracts](https://www.acquisition.gov/far/52.232-7)
- [FAR Subpart 4.7, Contractor Records Retention](https://www.acquisition.gov/far/subpart-4.7)

The contract’s incorporated text may differ from current online text. The download includes this guide, a PolyForm Noncommercial license, and the browser app with local `tokens.css`.
