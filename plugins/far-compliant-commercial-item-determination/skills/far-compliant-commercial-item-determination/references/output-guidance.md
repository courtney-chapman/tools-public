# 1. Output Types

## Output 1: Buyer Guidance Summary

### Purpose

This is a short working dashboard for the buyer. It helps the buyer quickly understand the likely classification, file risk, and key validation steps before relying on the determination.

### Audience

Internal buyer.

### Tone

Brief, practical, direct, and conservative.

### Should Include

- Quick classification table
- Buyer takeaway
- File risk
- Required validation

### Should Not Include

- Full FAR analysis
- Full COTS element-by-element justification
- Long source summaries
- Formal determination language

### Required Sections

1. Quick Classification
2. Buyer Takeaway
3. File Risk
4. Required Validation

---

## Output 2: Commercial Item and COTS Determination

### Purpose

This is the detailed market research determination written as the buyer’s completed evaluation for the procurement file.

### Audience

Procurement file.

### Tone

Formal, detailed, affirmative, non-conversational, and file-ready.

### Should Include

- Item reviewed
- Product or service description
- Sources reviewed
- FAR 2.101 commercial product / commercial service analysis
- Software / SaaS analysis, if applicable
- COTS element-by-element analysis
- Treatment of bundled services, if applicable
- Determination

### Must Not Include

- Coaching language
- “The buyer should...”
- “Recommended buyer actions”
- “Final approval rests with...”
- “Preparer note”
- Conversational caveats
- Unsupported conclusions

### Required Sections

1. Title: Commercial Item and COTS Determination
2. Item Reviewed
3. Product or Service Description
4. Sources Reviewed
5. Commercial Product / Commercial Service Analysis
6. Software / SaaS Analysis, if applicable
7. COTS Analysis
8. Treatment of Bundled Services, if applicable
9. Determination
