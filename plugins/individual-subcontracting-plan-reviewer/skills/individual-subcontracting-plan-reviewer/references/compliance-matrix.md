# Public regulatory compliance matrix

Independently checked against official Acquisition.gov codified FAR FAC 2026-01 (effective 2026-03-13) and DFARS change 2026-05-07 on 2026-11-20. This is a review aid, not a statement that every cited rule applies. First establish the solicitation/contract, agency, incorporated clause and date, alternate, plan type, contractor size, subcontracting possibilities, and any adopted deviation. **Mandatory** means required only after its stated trigger is established; **conditional** and **contract-specific** must never be treated as universal. Public citations below are the authority; a plan template is not.

## Edition and deviation boundary

The [FAR-overhaul FAQ](https://www.acquisition.gov/far-overhaul/faqs) explains that rewritten FAR text is issued as model deviation text for agency adoption. For an RFO or agency-specific clause, compare the **actual** solicitation/contract version and alternate with the codified baseline above; numbering, thresholds, assurance text, and report timing may differ. A missing governing clause is **Requires Review**, not a license to apply a generic template. Check agency supplements and current official reporting instructions when the user requests a contract-specific conclusion. FAR 19.705-6 assigns monitoring and acknowledgment duties to the **Government CO**; those are not prime-contractor plan-drafting obligations.

## Recommended review practices, not added regulation

Recalculate category and period totals; trace goal amounts to projected work, supplier research, and assumptions; reconcile worksheets and plan; flag unsupported claims. These are useful review methods, not additional mandatory plan elements. A heading alone does not show that an element has been completed.
